# Rancangan GaleriKarya
Solidity 0.8.24, OpenZeppelin ERC-721 dan AccessControl. Fungsi: `ajukanKarya(workId, uri)`, `setujuiKarya(workId)`, `terbitkan(workId, penerima)`, `tokenURI`, `ownerOf`, `kreatorOf`. URI tidak dapat diubah pengguna biasa. Event: `KaryaDiajukan`, `KaryaDisetujui`, `KaryaDiterbitkan`, dan `Transfer`.
